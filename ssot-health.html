ราคาตัวอย่างที่โปรแกรมอื่นจะได้รับ

ทดสอบจากโปรแกรม door cal โดยตรง

สำคัญที่สุด — การตรวจในหน้านี้บอกได้แค่ว่า "ฝั่งเซิร์ฟเวอร์ปกติ" แต่ยืนยันไม่ได้ว่า door cal ดึงจริง
door cal อาจดึงล้มเหลวแล้วใช้ fallback เงียบๆ โดยไม่แจ้ง ต้องทดสอบจากฝั่งนั้นด้วย

เปิด dcdoorproduction.netlify.app → กด F12 → แท็บ Console → วางคำสั่งนี้:

fetch('https://nny-spcompetitors.netlify.app/prices.json?v='+Date.now())
  .then(r => r.json())
  .then(d => console.log('✅ ดึงได้ | updated:', d.updated, '| SKU:', d.ours.length))
  .catch(e => console.error('❌ ดึงไม่ได้:', e.message));
ผลที่เห็นแปลว่า
✅ ดึงได้ | updated: ...เชื่อมสำเร็จ door cal จะได้ราคาใหม่แน่นอน
❌ ... CORS ...ติด CORS — บอกผม ผมแก้ _headers ให้
❌ Failed to fetchเน็ตมีปัญหา หรือ URL ผิด

ทดสอบแบบครบวงจร (แนะนำทำครั้งเดียว)

วิธียืนยัน 100% ว่าราคาไหลถึง door cal จริง
① เปิด หน้าแก้ราคากลาง เปลี่ยนราคา SKU ใดก็ได้ชั่วคราว เช่น ใส่ 9999
② กด 💾 บันทึกขึ้นเซิร์ฟเวอร์ รอ 1-2 นาที
③ กลับมาหน้านี้กด ตรวจอีกครั้ง — ถ้าเห็น 9999 แปลว่า SSOT อัปเดตแล้ว
④ เปิด door cal กด Ctrl+Shift+R (hard refresh) — ถ้าเห็น 9999 แปลว่าเชื่อมสำเร็จสมบูรณ์
⑤ แก้ราคากลับเป็นค่าเดิม แล้วบันทึกอีกครั้ง

สิ่งที่อาจทำให้ door cal ไม่อัปเดต

สาเหตุวิธีเช็ค / แก้
ใช้ fallback อยู่ โดยไม่รู้ตัวให้ Claude Code เพิ่มป้ายบอกสถานะบนหน้าจอ ว่าราคามาจากเน็ตหรือสำรอง
cache ในเบราว์เซอร์กด Ctrl+Shift+R · โค้ดต้องมี ?v=Date.now() ต่อท้าย URL
cache ใน localStorage 5 นาทีปกติ · รอ 5 นาที หรือใช้ load({force:true})
Netlify ยัง deploy ไม่เสร็จรอ 1-2 นาทีหลังบันทึก
ชื่อ SKU ไม่ตรงกันชื่อมีตัว × ไม่ใช่ x · ให้ Claude Code แสดงรายการที่ map ไม่เจอ
